# Photobooth

Photobooth is an Editor-only Unity tool that batch-renders prefab assets to
consistently framed PNG images. Open it from **Tools > Photobooth**.

See the [full documentation](https://github.com/JHaugland/Photobooth/blob/main/Packages/com.jhaugland.photobooth/Documentation~/index.md)
for installation, safety, configuration, troubleshooting, and extension
guidance.
